# CompIno IDE

Visual GTK3 IDE for the CompIno language (.cno files).

Features:
- Syntax highlighting (6 palettes)
- Auto-install Node.js + Arduino CLI (with configuration)
- Keyboard shortcuts (Ctrl+N, Ctrl+O, Ctrl+S, Ctrl+U, Ctrl+R)
- File operations, Compile, Upload
- Serial Monitor
- Config persistence
- Board detection and confirmation

## Build

```bash
sudo apt install libgtk-3-dev
make
./compino-ide
```
